# Official Google Fonts for RICH 2027

Downloaded 2026-09-30 from Google Fonts. Families: Cormorant Garamond, Montserrat, Noto Sans SC, Noto Serif SC.

WOFF2 binaries are unmodified official files. SOURCES.json records their official URLs, byte sizes and SHA-256 hashes. Each family includes its SIL Open Font License 1.1 file.

fonts.css preserves the existing requested weights, italics, font-display: swap and unicode-range rules; only source URLs are local. Chinese fonts retain Google’s split character ranges, so browsers fetch the relevant files as needed. The complete server bundle is not downloaded on every page visit.

All 10 itinerary-site HTML pages share this directory. It works on static hosting, including Vercel. Updates should use a new dated directory and update the HTML references after the assets have been uploaded.
